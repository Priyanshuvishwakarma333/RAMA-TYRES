# 🚗 RAMA TYRES

A responsive online tyre shop website built to help customers explore tyre products, compare prices and access tyre-shop information online.

- 💰 Display tyre prices
- 📱 Responsive design

- 📍 Location access

- 📦 Tyre data stored in JSON
